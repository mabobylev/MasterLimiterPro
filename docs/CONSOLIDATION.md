# История объединения

Рабочий проект — MasterLimiterPro. Варианты MasterLimiter и MasterLimiterPro-GUI
объединены 2026-10-16; пользователь подтвердил работу установленного плагина.
Предыдущие папки, версии и резервные архивы удалены по его указанию.

Исходная основа: Pro-GUI с исправлением несовместимых .h/.cpp истории GR;
сборка/идентификаторы из Pro. Ранний MasterLimiter использовал Maut/Limi,
текущий Pro — Mlim/Mlpr, поэтому это разные идентификаторы для DAW.
Дальнейшее развитие и миграция параметров описаны в DECISIONS.md.

JUCE 9.0.3 перенесена из раннего проекта без изменений исходников,
с сохранением лицензии. Точный commit — в ../JUCE_REVISION.
Старые кэши сборок, ссылавшиеся на /home/bma/Temp, были пересозданы.

При создании Git-репозитория включены только актуальные исходники, тесты,
документация и версия общего skill. JUCE/ и build/ остаются локально
и не включаются в Git. Текущая сборка устанавливается автоматически;
файлы сверяются по SHA-256. Проверенные DSP-результаты не заменяют
прослушивание и проверку восстановления проектов в конкретной DAW.
