# Master Limiter Pro

Единый проект Linux/VST3. В `Source/` объединены исправленная версия Pro
и расширенный интерфейс Pro-GUI: входные/выходные измерители, peak hold,
история подавления и сброс показаний. Локальная JUCE находится в `JUCE/`;
соседние каталоги и загрузка из сети для сборки не нужны.

## Подготовка нового checkout

JUCE не включена в репозиторий. Используется версия 9.0.3; точный commit
зафиксирован в `JUCE_REVISION`. Для нового checkout:

```sh
git clone --depth 1 --branch 9.0.3 https://github.com/juce-framework/JUCE.git JUCE
git -C JUCE rev-parse HEAD
cat JUCE_REVISION
```

Два последних значения должны совпасть. Существующая локальная JUCE позволяет
собирать проект без сети. GitHub Actions получает эту же закреплённую версию
и проверяет DSP/GUI под виртуальным X11, не устанавливая плагин на runner.

## Сборка

Нужны CMake >= 3.22, C++17 и системные Linux-зависимости JUCE
(см. `JUCE/docs/Linux Dependencies.md`).

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
```

Результат: `build/MasterLimiterPro_artefacts/Release/VST3/Master Limiter Pro.vst3`.
Если проект перемещён, сначала удалите старый `build/`: кэш CMake содержит
абсолютные пути.

## Установка

```sh
python3 tools/install_vst3.py \
  --source "build/MasterLimiterPro_artefacts/Release/VST3/Master Limiter Pro.vst3" \
  --destination "$HOME/.vst3/Master Limiter Pro.vst3"
```

После успешной сборки VST3 автоматически копируется в `~/.vst3/`.
Команда выше позволяет повторить установку вручную с проверкой SHA-256
и заменой файлов через новые inode. Для предварительной проверки добавьте
`--dry-run`. Скрипт не удаляет неизвестные файлы в destination.
После обновления перезапустите хост, чтобы загрузить новый бинарник. Затем обновите список
плагинов в DAW.

## Обработка и интерфейс

GUI оформлен в стиле KickDuck1 и масштабируется от 900×580 до 1800×1100.
Input — оранжевый, Output — зелёный, GR — розовый, основные ручки — фиолетовые.
Осциллограмма и регуляторы занимают левую колонку одной ширины;
измерители справа используют всю высоту, включая минимальное окно.
Двойной щелчок возвращает правильное значение по умолчанию каждой ручки.

Основной ограничитель работает с предвидением 0–20 ms. Кнопка TRUE PEAK
включает дополнительную защиту межсэмпловых пиков (8× FIR, внутренний запас
0.75 dB). По умолчанию она выключена, старые проекты загружаются с TP OFF.
В режиме TP ручка LIMIT подписана в dBTP, в обычном — в dB.

Задержка основного ограничителя плюс фильтры/защитная ступень сообщается DAW:
на 48 kHz это 1073 samples / 22.354 ms. Она одинакова при TP ON/OFF и bypass,
не меняется при автоматизации Lookahead. В других sample rates значение
пересчитывается и видно в шапке. Чистый/SP тракт сохраняет сигнал с учётом
новой компенсируемой задержки.
Stereo Link: 0% — независимая обработка, 100% — общий gain для L/R.
Порядок ручек: INPUT → LOOKAHEAD → RELEASE → STEREO LINK → LIMIT.
INPUT: −24…+24 dB, ноль в центре, дуга от нуля и явный знак значения.
LIMIT: −6…0 dB для новых экземпляров; по умолчанию −1 dB.
В проектах со старым состоянием LIMIT сохраняет прежний диапазон −3…0 dB
и автоматизацию Ceiling. Для расширенного диапазона используйте новый экземпляр.
Название INPUT оставлено, поскольку ручка регулирует входное усиление.
Основные параметры сглаживаются; снижение потолка применяется сразу.

Измерители: sample peak, RMS (300 ms), gain reduction, выходной peak hold
и оценка выходного true peak (8× интерполяция).
В центре — реальная осциллограмма выхода L/R за 6 s; сверху — GR с той же
временной шкалой. В каждом участке сохраняются min/max и максимальный GR,
поэтому короткие пики не исчезают, а противофаза не отменяет каналы.
История накапливается и при закрытом GUI; остановка аудио удерживает кадр.
RMS измеряется после Input gain/на выходе и остаётся отдельной метрикой.

OUTPUT LOUDNESS / LUFS измеряет окончательный выход, включая TP и bypass:
**M** — последние 400 ms, **S** — последние 3 s, **I** — накопленное измерение
с абсолютным и относительным гейтингом. До заполнения окна отображается −inf.
Обновление раз в 100 ms; mono учитывается один раз, stereo — сумма мощности
каналов без отмены противофазы.

**RESET METERS** сбрасывает также M/S/I. Измерение продолжается, пока хост
передаёт аудиоблоки; при отсутствии блоков показания удерживаются. Оно не
перезапускается автоматически при перемотке/loop и не сохраняется в state.
Для измерения отдельного фрагмента сбросьте метры перед его воспроизведением.
В некоторых хостах обработка продолжается и при остановленном транспорте;
I исключает тишину гейтингом, M/S при этом продолжают обновляться.

## Проверки

```sh
cmake --build build --target MasterLimiterTests -j2
ctest --test-dir build --output-on-failure
```

Для PNG-превью реального GUI: из `build/` запустите
`MASTERLIMITER_PREVIEWS=1 ./MasterLimiterTests`. Изображения появятся
в `build/previews/`. Для проверки без установки можно задать
`-DMASTERLIMITER_COPY_PLUGIN_AFTER_BUILD=OFF` при конфигурации.
По умолчанию установка включена.

Для приёмки VST3 в REAPER используйте [чек-лист](docs/DAW_CHECKLIST.md).
Независимый аудит float32-выхода процессора через FFmpeg описан
в [TRUE_PEAK_AUDIT.md](docs/TRUE_PEAK_AUDIT.md). Аудиофайлы и полные журналы
создаются только в игнорируемом build/.

## Ограничения и продолжение

True Peak — проверенная на тестовых сигналах защита, а не сертификат
соответствия BS.1770. Независимая 16× интерполяция проверяет выход с допуском
0.1 dB; математическая гарантия для любого сигнала/ЦАП не заявляется.
При включении TP из остановленного режима предусмотрены прогрев 30 ms
и кроссфейд 20 ms; полная защита действует после перехода. Резкие изменения
Limit могут создавать переходные процессы; bypass отключает ограничение.
LUFS M/S/I рассчитывается K-взвешиванием и гейтингом Integrated;
подробности и точность — в [LOUDNESS.md](docs/LOUDNESS.md).
Соответствие BS.1770 не сертифицировано.
По умолчанию включён чистый тракт: сигнал ниже Limit проходит с заданным
входным усилением и задержкой без постоянной сатурации. Кнопка SOFT CLIP
включает прежнее tanh-насыщение перед ограничителем; переключение сглажено
за 20 ms. Старые состояния без этого параметра загружаются с Soft Clip ON,
чтобы сохранить их характер. Выключение кнопки и последующее сохранение
запоминаются в проекте. Soft Clip может добавлять гармоники и алиасинг:
Soft Clip сам работает на базовой частоте: 8× применяется только к отдельной
ступени TP после основного лимитера. GR показывает работу обеих ступеней,
без учёта изменения формы сигнала в Soft Clip.

Быстрый перевод Limit вниз
и переключение host bypass могут быть слышны. Качество на музыкальном
материале и поведение конкретных DAW требуют прослушивания и проверки.

Решения: `docs/DECISIONS.md`. Дальнейшие этапы: `docs/PLAN.md`.
